### 🚀 `execute_projects.sh`

#### 🔬 Medical AI & Computer Vision
* 👁️ **[Glaucoma-Segmentation-MiTB3](https://github.com/akamecofficial/Glaucoma-Segmentation-MiTB3):** Clinical deep learning pipeline utilizing YOLOv8 localization, MiT-B3 (Mix Vision Transformer) U-Net segmentation, and Monte Carlo (MC) Dropout uncertainty analysis for retinal fundus imaging.
* 🩺 **DermaLens:** Interactive skin cancer classification system leveraging an EfficientNet backbone to classify dermoscopic lesions into 7 diagnostic categories with real-time probability audits.
* 👤 **VidGen (DeepFace Video Analyzer):** Video face analysis and deepfake detection tool featuring sequential frame processing and RAM optimization to prevent OOM errors during inference.

#### 🧠 LLMs & Interpretability
* 🔬 **LLM Mechanistic Interpretability Dashboard:** A tool built with TransformerLens and Streamlit to inspect GPT-2 internals, featuring Logit Lens tracking, Sparse Autoencoders (SAE) feature extraction, and live Activation Steering.

#### 📈 Financial NLP & Algorithmic Trading
* 📊 **CryptoTrader (BTC Tracker):** Asynchronous technical analysis suite interfacing directly with the Binance API via CCXT, featuring custom Tkinter canvas charting and TA-Lib indicators.
* 📰 **Bitcoin News Analyzer & CoinSentiment:** Multithreaded sentiment analysis pipelines tracking real-time crypto sentiment across news feeds and social endpoints using NLTK/VADER and interactive visualizers.

#### 🎮 Interactive Systems & Mobile
* ⚔️ **The Pale Sorcerer:** Custom 3D action roguelike featuring procedural dungeon generation, modular elemental spell systems, and custom audio engineering. *(Coming soon to Steam)*
* 🎵 **BeatNeko:** High-performance music streaming ecosystem built on Flutter and Firebase with custom batch audio caching and on-device vector recommendations.
